# Booksmith

**An open, developer-friendly scheduling platform for service businesses.**

Booksmith is a Calendesk competitor that prioritizes three things Calendesk gets wrong: transparent pricing with a real free tier, first-class API/developer experience, and multi-tenant white-label support from day one.

---

## Product Positioning

| | Calendesk | Calendly | **Booksmith** |
|---|---|---|---|
| Free tier | No (14-day trial only) | Yes (1 event type) | **Yes (1 employee, 100 bookings/mo)** |
| API-first | Partial (Pro only) | Yes | **Yes (all plans)** |
| White-label | Enterprise only | No | **Pro and up** |
| Website builder | Yes | No | **Yes (with custom domains)** |
| Payments | Stripe only | Stripe/PayPal | **Stripe, PayPal, LemonSqueezy** |
| SMS notifications | Paid add-on | No | **Included (fair-use)** |
| Self-host option | No | No | **Yes (Docker)** |
| Open source | No | No | **Core is MIT** |

---

## Target Users

1. **Solo practitioners** — therapists, tutors, coaches, consultants, personal trainers
2. **Small service businesses** — salons, studios, clinics (2-25 staff)
3. **Developers** — embedding scheduling into their own SaaS products via API
4. **Agencies** — managing bookings across multiple client brands (white-label)

---

## Core Value Propositions

### 1. Generous Free Tier
Unlike Calendesk ($97/mo minimum), Booksmith offers a real free plan: 1 employee, 1 service, 100 bookings/month, basic email notifications. Enough to run a solo practice indefinitely.

### 2. API-First Architecture
Every feature available in the UI is available through the REST API. Webhooks for all events. SDKs for JS/Python/Go. Embeddable booking widgets with 3 lines of code.

### 3. White-Label from Pro
Agencies and SaaS builders can remove Booksmith branding, use custom domains, and style the booking pages to match their brand — starting at the Pro tier, not locked behind enterprise sales calls.

### 4. Self-Hostable
Run the entire platform on your own infrastructure with a single `docker compose up`. Your data, your servers, your rules. The managed cloud version is there for convenience.
